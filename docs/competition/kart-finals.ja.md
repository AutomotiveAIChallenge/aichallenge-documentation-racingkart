## 実車両で走らせるときの注意点 { #real-vehicle-notes }

### V2X の通信遅延 { #v2x-delay }

実車両は無線ネットワークを利用して位置情報を共有するため、遅延と欠損が発生します。実測では、平均 90 ms 程度の遅延が発生することがわかっています。
遅延への対処はアルゴリズム側の責務です。受信位置の外挿、古いデータの破棄、遅延を前提とした余裕距離の確保を行うことを推奨します。

### 駆動力と速度 { #traction }

- ステアを切った状態で発進するには、スロットルモーターに大きなトルクが必要です。ステアを最大まで切った状態では発進できないことがわかっているため、ステアを切ったまま発進しないことを推奨します。
- 実車両の上限速度は 25 km/h 程度です。

### 自己位置と通信 { #localization }

- RTK-GNSS の自己位置推定はインターネット接続に依存しているため、精度が悪くなったり、途絶が発生したりすることがあります。

### IMU バイアスと accel/brake map { #imu-bias-and-accel-brake-map }

- 車両固有の IMU バイアスと accel/brake map の設定は運営側で実施します。

### スタート時の挙動 { #start-behavior }

- スタート時の並び順は縦一列で、シミュレータとは異なります。
- レース開始を表すトピックは配信されず、手動モードから自動モードに切り替わるのみです。スタート位置での待機中にスタック判定が働いて、いきなり後退や切り返しを始めてしまわないよう、各チームで対処する必要があります。
